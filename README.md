# hateeze

Незавершённый Windows-твикер для игр. Сейчас в репозитории каркас .NET-проектов, макет интерфейса, спецификация, план и исследовательские материалы. Рабочего движка твиков и готового приложения пока нет.

## Стек и состояние

- План: C# / .NET 10, WinForms + WebView2, React + TypeScript + Vite; Windows x64.
- `src/Hateeze.App` пока открывает пустую WinForms-форму.
- `src/Hateeze.Core` — заготовка библиотеки; тестовый проект существует, тесты ещё не написаны.
- `web/` и `build.ps1` пока отсутствуют. Упоминания этих путей в плане описывают будущую реализацию.
- `docs/research/` содержит исследования, JSON-каталоги, примеры C# и ответы API. Это материалы для проверки и интеграции, а не готовые модули приложения.

## Проверка на Windows

Нужен .NET 10 SDK.

```powershell
dotnet build hateeze.sln
dotnet test hateeze.sln
```

Проверка каталогов твиков (нужен только Node.js):

```bash
node tools/catalog/validate.mjs
node --test tools/catalog/*.test.mjs
```

Наличие тестового проекта само по себе не означает наличие проверок. Системные изменения, установщики и экспериментальные пробы на машине разработчика не запускать.

## Работа в облаке

Исследования, интерфейс, контракты и тесты с поддельными платформенными сервисами можно развивать в облаке. WinForms, WebView2, ETW, реестр, службы и драйверы требуют отдельной проверки на Windows. Успешная сборка в Linux не подтверждает работоспособность этих функций.

Локальная история чата Claude не переносится через GitHub. Контекст для нового сеанса хранится в `CLAUDE.md` и `docs/HANDOFF.md`; папка `.claude/` исключена из Git.
