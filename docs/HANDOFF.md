# Передача проекта в новый сеанс Claude

Обновлено 26 октября 2026 года, облачный сеанс.

## Что существует

- Репозиторий `hateeze/hateezetw` на GitHub; рабочая ветка облачного сеанса — `claude/nice-mccarthy-0nqgnt`.
- Три проекта: приложение WinForms, библиотека Core, тестовый проект xUnit. Приложение открывает пустую форму; Core — маркер сборки; тестов C# нет.
- Спецификация, предварительный план, HTML-макет.
- Исследования в `docs/research/`; их состояние и пробелы — в [`docs/research/STATUS.md`](research/STATUS.md).
- [`docs/DECISIONS.md`](DECISIONS.md) — принятые решения по расхождениям спецификации, плана и исследований (стек UI, протокол моста, горячая клавиша и др.).
- [`docs/catalog-format-v1.md`](catalog-format-v1.md) — формат каталога твиков. Валидатор без зависимостей: `node tools/catalog/validate.mjs`, тесты: `node --test tools/catalog/*.test.mjs`.

## Что ещё не сделано

- Нет `web/`, `build.ps1`, хоста WebView2, RPC, платформенного слоя, движка, журнала и отката.
- Нет исследований установщика драйвера NVIDIA, ввода/сети (есть только JSON) и мониторинга/прерываний (есть только код зонда).
- В JSON не перенесены записи приватности и очистки из отчёта по службам.
- Каталоги исследований не приведены к формату v1: 16 ошибок валидатора, список — в `STATUS.md`. Это делается при импорте в продукт (Task 6); файлы исследований не меняются.
- Task 5 плана описывает React; по решению D1 его нужно переписать под Svelte 5 перед выполнением.
- Реальная установка драйверов, работа ETW/NVAPI и системных изменений требует Windows и отдельной контролируемой валидации.
