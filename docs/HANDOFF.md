- Ветка `main`, исходный коммит `4d2c477` (`chore: solution scaffold, spec, plan and design mockup`). На момент осмотра Git remote отсутствовал.

## Что ещё не сделано

- Нет `web/`, `build.ps1`, хоста WebView2, RPC, платформенного слоя, движка, журнала и отката.
- Нет реализованных тестов и доказательства готовности функций из спецификации.
- Отдельных исследовательских отчётов по вводу/сети и мониторингу в текущей папке нет; есть каталог ввода/сети и примеры мониторинга. Не считать эти темы завершёнными без проверки.
- Реальная установка драйверов, работа ETW/NVAPI и системных изменений требует Windows и отдельной контролируемой валидации.
- Локальные диалоги, память и плагины прежнего сеанса Claude через репозиторий не передаются.

Провести сверку спецификации, плана и исследований. Создать краткую таблицу: тема, имеющиеся материалы, открытые вопросы, следующий шаг. Проверить совместимость пяти JSON-каталогов с будущей общей схемой; не переносить их автоматически в продукт. После этого продолжить недостающие исследования либо согласованный фундамент приложения. Не начинать одновременно все разделы плана.
