# Решения по проекту

Владелец поручил выбрать варианты самостоятельно (2026-10-26). Ниже решения по расхождениям между спецификацией, планом и исследованиями. Любое из них можно пересмотреть; при изменении правится эта запись и связанные документы.

| # | Вопрос | Решение | Почему |
|---|---|---|---|
| D1 | Фреймворк интерфейса | **Svelte 5 (runes) + TypeScript + Vite**, версии — по `docs/research/shell-ui-liquid-glass.md` §9.2. Папка остаётся `web/`, как в спецификации | Исследование сравнило четыре варианта: scoped CSS из коробки, нет ловушек хуков, малый рантайм. React в плане выбран до исследования. Task 5 плана переписывается под Svelte при выполнении |
| D2 | Протокол моста | Как в спецификации §3: `{id, method, params}` → `{id, result}` / `{id, error}`, события `{event, data}`, долгие операции — `op.progress` / `op.done` / `op.cancel` | Формат уже описан в спецификации и плане и читается без расшифровки. Конверт `{t,id,m,p}` из исследования не добавляет возможностей |
| D3 | Адрес интерфейса внутри WebView2 | `https://app.hateeze.example/` | Домен `.example` зарезервирован (RFC 2606/6761) и никогда не станет реальным сайтом |
| D4 | Ctrl+Alt+Shift+R | Двойное нажатие за 3 с → окно с отсчётом 10 с и кнопкой «Отмена» → «Вернуть всё» → перезагрузка. Если откат прошёл с ошибками, перезагрузки нет, показывается итог | В полноэкранной игре окно отсчёта не видно, поэтому одиночное случайное нажатие откатило бы всё и перезагрузило ПК |
| D5 | Модель процессов | v1 — один процесс с правами администратора и WebView2, с мерами из исследования оболочки §5.8: ассеты только из ресурсов exe, запрет навигации и сторонних страниц, UserDataFolder в `%LOCALAPPDATA%`, `WebView2Loader.dll` не в `%TEMP%`. Разделение на два процесса — если его потребует ревью безопасности | Сторонний контент не загружается. Разделение удваивает межпроцессное взаимодействие и сроки |
| D6 | Каталог приложений | Копия каталога вшита в exe как запасная. Свежий каталог берётся подписанным файлом из последнего релиза GitHub (тот же канал, что `latest.json`); при ошибке подписи или сети используется вшитый | Ссылки вендоров меняются (`app-installers-ddu-update.md` §0, п. 1); вшитая копия сохраняет работу офлайн |
| D7 | Шрифты | Segoe UI Variable (системный) с запасными по макету + JetBrains Mono локально. Inter не используется | Макет утверждён и использует Segoe; системный шрифт не нужно поставлять |
| D8 | Формат каталога твиков | `docs/catalog-format-v1.md` + валидатор `tools/catalog/validate.mjs`. Файлы исследований не меняются; приведение к формату — при импорте (Task 6) | Закрывает расхождения каталогов с `TweakDef` из плана: `kind: info`, `options` по виду, `{{nvidiaGpuIndex}}`, `nic` с `reset`, `detect`, HKCU = интерактивный пользователь |
| D9 | Схема «hateeze Low Latency» на X3D с двумя CCD и Intel hybrid | В v1 не предлагается; вместо неё — информационная карточка `cpu.x3d-dual-ccd-keep-balanced` | Исследование питания §0 п. 2: на таких CPU схема может ухудшить игры, замеров нет |
| D10 | .NET SDK в облачном окружении | Не устанавливается без отдельного разрешения владельца | Владелец запретил запускать установщики. Сборка и тесты C# — на Windows или после разрешения |

Открытыми остаются: сертификат подписи кода, минимальная версия WebView2 Runtime, нужна ли в v1 функция удержания таймера (спецификация её содержит, исследование сомневается).
